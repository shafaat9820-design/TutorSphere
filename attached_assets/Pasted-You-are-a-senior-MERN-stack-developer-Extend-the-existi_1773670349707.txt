You are a senior MERN stack developer.

Extend the existing TutorConnect MERN application by implementing a fully functional **Admin Dashboard** with complete platform management capabilities.

The Admin panel must be secure, scalable, and only accessible to users with role "admin".

---

ADMIN AUTHENTICATION

Admin users must log in using the normal login system but must be redirected to:

/admin/dashboard

if their role is "admin".

Use role-based middleware to protect all admin routes.

Only admins should access these routes:

/admin/dashboard
/admin/users
/admin/posts
/admin/payments
/admin/reports

If a non-admin user tries to access admin routes, return a 403 unauthorized error.

---

ADMIN DASHBOARD OVERVIEW

The admin dashboard must display key platform statistics including:

* Total Users
* Total Tutors
* Total Parents
* Total Tuition Posts
* Total Payments
* Total Revenue

Display these statistics using dashboard cards.

Example layout:

Card 1: Total Users
Card 2: Total Tutors
Card 3: Total Tuition Posts
Card 4: Total Revenue
