You are a senior full-stack engineer. Build a complete production-style MERN stack web application called **TutorConnect**.

This platform connects parents/students who need tutors with tutors searching for tuition opportunities. Tutors must pay a small fee (₹49) to unlock the contact details of the parent/student who posted the tuition requirement.

The system must be secure, responsive, scalable, and follow clean architecture.

---

TECH STACK

Frontend:

* React.js
* Tailwind CSS
* React Router
* Axios
* Responsive UI (mobile, tablet, desktop)

Backend:

* Node.js
* Express.js
* RESTful API architecture
* JWT authentication
* bcrypt password hashing

Database:

* MongoDB using Mongoose

Payments:

* Razorpay payment gateway

Architecture:

* MVC pattern
* Clean folder structure
* Environment variables for secrets

---

APPLICATION CONCEPT

The platform works like a tuition marketplace.

Parents or students create tuition requirement posts.

Tutors browse those posts and apply.

To view the contact details of the parent/student, the tutor must pay ₹49.

After successful payment the tutor can unlock and view the phone number.

The payment goes to the platform owner.

---

USER ROLES (ROLE BASED ACCESS CONTROL)

The application must support 3 roles:

1. Admin
2. Tutor
3. Parent/Student

During registration the user must select a role.

Each role must have different permissions.

* Register

* Logout

Registration fields:

* Full Name
* Email
* Password

* Role selection (Tutor or Parent/Student)

Security requirements:

* Passwords must be hashed using bcrypt
* Use JWT authentication
* Store tokens securely
* Protect private routes
* Validate all user inputs

---

PARENT / STUDENT FEATURES

Parents or students can:

Create tuition posts.

Each post must include the following fields:

* Title
* Class (example: KG, Class 10)
* Subjects
* Gender preference (optional)
* Medium (English/Hindi)
* Mode (Home Tuition / Online)
* Address / Location
* Duration (hours per day)
* Days per week
* Monthly fee
* Description or additional notes
* Contact phone number
* Created date

Important:

The contact phone number must remain **hidden**.

Tutors can only see the phone number after payment.

Parents should also be able to:

* View their created posts
* See which tutors applied
* Manage their posts

---

TUTOR FEATURES

Tutors should be able to:

Browse all tuition posts.

See important details except contact number.

Apply for tuition.

Unlock the parent's phone number by paying ₹49.

After successful payment:

The tutor can see the phone number and contact the parent.

Tutors should also be able to:

* View their applied posts
* See which posts they unlocked
* Manage their profile

---

FILTER SYSTEM (LIKE OLX)

Tutors must be able to filter tuition posts using:

* Class
* Subject
* Location
* Fee range
* Mode (online / home)
* Medium
* Gender preference

Also include:

* Search bar
* Pagination
* Sorting by latest posts

---

PAYMENT SYSTEM

Use Razorpay for payment integration.

Payment flow:

Tutor clicks "Unlock Contact".

System opens Razorpay payment window.

Tutor pays ₹49.

After successful payment:

* Save payment record
* Mark contact as unlocked
* Display parent's phone number

Payment records must include:

* Tutor ID
* Tuition Post ID
* Amount
* Payment status
* Payment date
